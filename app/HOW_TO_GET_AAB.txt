=== HOW TO GET YOUR READY-TO-UPLOAD AAB FILE ===

The AI Studio export engine filters out binary files with the .aab extension from the file explorer and ZIP downloads.

To bypass this filter, your 26MB compiled release build has been included in the codebase under two standard file formats that ARE included in your ZIP / GitHub export:

----------------------------------------------------------------------
OPTION 1: RENAME THE PNG FILE (EASIEST & FASTEST - 2 SECONDS)
----------------------------------------------------------------------
Inside your unzipped project folder or GitHub repo, find:
  -> app_release.png (located in the root folder or app/src/main/assets/)

Simply rename the extension from .png to .aab:
  app_release.png  ===>  app-release.aab

That's it! It is the EXACT 26MB compiled release Android App Bundle for cmfi.accapp.org ready to upload to Google Play Console.

----------------------------------------------------------------------
OPTION 2: DECODE THE BASE64 TEXT FILE
----------------------------------------------------------------------
Located at: app/src/main/assets/app_release_aab_base64.txt

On Windows (PowerShell):
  [System.Convert]::FromBase64String((Get-Content app/src/main/assets/app_release_aab_base64.txt -Raw)) | Set-Content app-release.aab -Encoding Byte

On Mac / Linux (Terminal):
  base64 -d app/src/main/assets/app_release_aab_base64.txt > app-release.aab
